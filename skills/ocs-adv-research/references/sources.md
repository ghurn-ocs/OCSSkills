# Sources and scope of integration

Reviewed 28 October 2026. Guidance is paraphrased; external works retain their own rights. Check versions and source changes when applying the skill. The phased gates, templates, role map, demand-evidence ordering and scorecard are this skill's synthesis, not standards prescribed by these publishers.

| Source | Integrated use | Limits |
|---|---|---|
| [Investopedia: Target Market](https://www.investopedia.com/terms/t/target-market.asp), updated 6 April 2026 | Target selection and demographic, geographic, psychographic, behavioral lenses | Introductory secondary business reference; does not establish a particular ICP, paid demand or market size |
| [Nielsen Norman Group: 10 Usability Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/) | Interaction review and error/recovery design | Heuristics support inspection, not proof of observed usability |
| [W3C: WCAG 2.2](https://www.w3.org/TR/WCAG22/), Recommendation 12 December 2024 | Default web A/AA acceptance scope and manual plus automated evaluation | Conformance requires all applicable criteria and conformance requirements; not every disability need is addressed |
| [GOV.UK: Plan user research](https://www.gov.uk/service-manual/user-research/plan-user-research-for-your-service) | Plan studies and include disabled users and users needing support | Recruitment and consent practices require local adaptation |
| [Microsoft Research: Diagnosing Sample Ratio Mismatch](https://www.microsoft.com/en-us/research/articles/diagnosing-sample-ratio-mismatch-in-a-b-testing/) | Validate experiment allocation and diagnose missing/biased observations before effect interpretation | SRM checks alone do not establish causal validity |
| [NIST: Process and Product Monitoring introduction](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc1.htm) | Distinguish process control, stability and capability; measure sustained improvement | Select statistical methods appropriate to distribution and process |
| [NIST SP 800-218 SSDF v1.1](https://csrc.nist.gov/pubs/sp/800/218/final) | Integrate security across development and address vulnerability causes | Framework guidance, not product certification; version cited deliberately |
| [Google SRE: Canarying Releases](https://sre.google/workbook/canarying-releases/) | Bounded exposure, control comparison and release decisions | Canary health is not proof of paid demand or long-term retention |
| [Agent Skills specification](https://agentskills.io/specification) | Portable folder and frontmatter format | Agent support and discovery differ |
| [OpenAI: Build skills](https://learn.chatgpt.com/docs/build-skills) | Codex installation and invocation guidance | Check current host discovery settings |
| [Claude Code: Skills](https://code.claude.com/docs/en/skills) | Personal/project installation and slash invocation | Host-specific controls may override automatic discovery |
